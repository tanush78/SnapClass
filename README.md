# ai-attendance-project-app
SnapClass — AI-Powered Attendance System
SnapClass is an AI-powered attendance management system designed to make classroom attendance faster, smarter, and more efficient.
Features

* Face Recognition: Identify students using facial recognition.
* Voice-Based Attendance: Support attendance through voice-based identification.
* QR Code Enrollment: Simplify student enrollment using QR codes.
* Teacher and Student Interfaces: Separate interfaces for teachers and students.
* Attendance Management: Streamline classroom attendance workflows.

Technology Stack

* Python
* Streamlit
* OpenCV / Face Recognition
* NumPy and Pandas
* Supabase
* QR Code Generation

Installation

1. Clone the repository:
`git clone https://github.com/tanush78/ai-attendance-project-app.git`
2. Navigate to the project directory:
`cd ai-attendance-project-app`
3. Install dependencies:
`pip install -r requirements.txt`
4. Configure the required environment variables and Supabase credentials according to the project instructions.
